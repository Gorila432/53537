# 53537

Para instalar el analizador en Visual Studio CODE y utilizarlo, seguir los pasos:

1- Descargar el repositorio como zip y extraerlo en su computadora.
2- Copiar la carpeta extraida en Visual Studio Code.
3- Entrar al archivo de texto llamado "input.txt" e ingresar una cadena válida para la gramática AnalizadorFOR.g4 (ya hay cadenas de ejemplo en el archivo).
4- Abrir una terminal nueva para la carpeta AnalizadorFOR y escribir "node index.js" para analizar las cadenas.

Se muestra paso por paso lo pedido en la tarea. El análisis léxico y sintáctico, tabla de lexemas y tokens, árbol de derivación (en texto garantizado; gráfico al presionar F5 en Visual Studio CODE) y resultado (salida) del código ingresado, junto a su interpretación en JavaScript.
Si la cadena ingresada es inválida, aparece debajo de la tabla de lexemas y tokens un aviso de error, junto con la línea y posición en la que existe el error y qué es el valor esperado.
